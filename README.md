# Chatting Web

A real-time web-based chatting application designed to allow users
to communicate through a simple and responsive interface.

## Features

- User registration and login
- One-to-one messaging
- Real-time message delivery
- Chat history
- Online/offline user status
- Responsive chat interface

## Tech Stack

### Frontend
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- Socket.IO

### Database
- MongoDB

### Development Tools
- Git
- GitHub
- VS Code
- Claude Code
